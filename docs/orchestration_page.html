What a gate decides

A gate does not ask “is this good?” It asks whether the output is good enough for the next step to mean anything. Gates are deterministic and cheap, so they run on every step of every run.

PASS

Continue.

DEGRADE

Continue, but mark the run. A thin run is always visible in the output — never silently.

RETRY

Re-run the step once, handing it the failure as feedback.

ESCALATE

Stop. No PDF. Used only where continuing would produce something a family might act on and be harmed by.

gate_retrieval is the one that matters most. Empty or fabricated retrieval makes every step after it fiction and looks completely normal in the PDF — which is how it caught match_rank returning zero cards from a 30,414-row table on its first live run.

Two rules the drawing encodes

Numbers belong to modules

Counts, bands, tiers and rates are computed by deterministic code and handed to the agents. An agent that states a number it was not handed is a bug, not a phrasing issue.

Debate is one source, not the shape

Every program and competition database resolves to one common schema through data/sources.json. Adding robotics, math or business competitions is a data change — drop the file, register it, map its levels onto the six rungs. No step, prompt or gate moves.

The corpus and the rate table answer different questions

The corpus answers “what does an admit to this school look like?” The published rate table answers “how selective is this school?” The corpus never produces an admit rate: it is self-selected, and 32.6% of posts omit rejections.
